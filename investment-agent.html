Investment Agent

An AI stock research agent that turns natural-language investment questions into structured, actionable insights using NSE-linked market data, news retrieval, and agent-based orchestration.

Focus Agentic AI • Stock research
Tools LangGraph • DuckDuckGoSearch • NSE data
Repo View on GitHub

01 / problem

Researching stocks from everyday language

The core challenge in this project was translating ordinary investor questions into an AI workflow that could resolve the right NSE company, fetch the right market data, and summarize meaningful signals from recent news.

Instead of forcing a user to know exact ticker names or navigate multiple sources manually, the agent handles the intent mapping and retrieval process automatically.

02 / approach

Symptom-to-signal pipeline

  • Used natural-language understanding to identify the target company or symbol from a query
  • Applied deterministic NSE symbol resolution with confidence checks and ambiguity handling
  • Fetched live quotes and recent news through retrieval layers designed to support structured results
  • Combined the findings into human-readable summaries and machine-friendly JSON output

03 / architecture

LangGraph state orchestration

The implementation is organized around a LangGraph StateGraph, which makes the workflow transparent and reusable. Each stage is responsible for a specific step in the pipeline:

  • Resolve symbol or company name from user intent
  • Fetch quote data from NSE-backed sources
  • Retrieve recent news and structured snippets
  • Generate a final report with both summary and structured output

04 / results

Practical AI workflow

The project demonstrates how an agent can move from raw prompt input to a useful financial research response. It also includes state persistence using SqliteSaver, which makes replay and debugging much easier during iterative development.

In practice, this makes the agent feel like a research assistant rather than a simple chatbot.
